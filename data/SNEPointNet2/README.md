### Dataset

The concrete defect point-cloud dataset was obtained from the original SNEPointNet2 research repository.

**Source:** https://github.com/neshatbln/SNEPointNet2

The dataset contains 102 point-cloud segments collected from four reinforced concrete bridges. The raw data is available in the repository's `Data` directory.

The dataset is not included in this repository. Users should download it from the original source before running the analysis notebooks.
